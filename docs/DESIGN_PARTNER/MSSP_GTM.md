Status: **process durable** — multi-tenant product architecture is real; channel
program metrics and partner references remain open until trained partners exist.  
Related: [`DEAL_DESK.md`](./DEAL_DESK.md) Band C `MSSPPartner`, [`ICP_WEDGE.md`](./ICP_WEDGE.md)

**Honesty:** Do not claim “2–3 trained partners” or confidential MQ references
until real. This playbook is the Execute wedge *motion*, not market presence.

---

## 1. Why MSSP is the Execute wedge

When direct enterprise brand is weak, channel multi-tenancy is a classic
Challenger → Leader path:

| Asset already in product | GTM use |
|--------------------------|---------|
| Parent/child tenants + isolation | Co-managed client portfolio |
| Metered packs / entitlements | Invoice metering truth for partner QBR |
| White-label report branding | Partner leave-behind without evidence ID lies |
| Short-term assessment packs | Co-managed ASV-style resale unit |
| Executive trends + honestyTrust | Partner QBR scorecard (Measured %, Fixed survival) |

Do **not** wait for Fortune-500 logos before packaging the MSSP motion.

## 2. Offer units (sell these)

| Unit | Product mapping | Partner value |
|------|-----------------|---------------|
| **Co-managed ASV / short-term assessment pack** | ShortTermAssessments meter + Snapshot missions | Fixed-scope deliverable partners can resell |
| **Continuous client portfolio** | Child tenants + schedules + findings queue | Ongoing managed service |
| **QBR proof pack** | Evidence packs + executive trends + honestyTrust | Quarterly business review with Measured language |
| **Invoice metering** | Usage meters + approvalReference | Transparent burn; no fake self-serve checkout |

Commerce remains **invoice / order form**. `paymentProcessorStatus: NotConfigured`
is fine — partners model margin offline from meter definitions.

## 3. Partner program bar (before “trained partners” claim)

Close each gate with real evidence before GTM language:

| Gate | Evidence |
|------|----------|
| Dogfood partner | One internal or design-partner org on MSSPPartner package |
| Two child tenants | Isolation leave-behind + portfolio UI |
| QBR pack delivered | Branded evidence pack + honesty trust metrics |
| Invoice metering exercised | Meter burn reviewed in partner session |
| Reference consent | Written consent for confidential MQ/Wave call |

**Target:** 2–3 trained partners — **status: zero until trained**.  
Use MSSP references as first MQ confidential refs only after consent.

---

## 4. Weekly partner operating rhythm

1. Portfolio “Needs you” across child tenants  
2. Measured path → remediation → revalidation for top findings  
3. Denied-never-queued and signature verification rates on honestyTrust  
4. Meter burn vs term package  
5. One anonymized proof-loop KPI export (design-partner workspace) for SE enablement
