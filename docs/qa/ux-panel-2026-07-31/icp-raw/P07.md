### 4. Copy-as-curl is excellent but incomplete for safe retries (P2, delight/task)
Reference console generates real curl with `$PERISCAN_API_URL` / Bearer key and request body — core JTBD win:

```484:506:/Volumes/DataSSD1/test/periscan/apps/web/src/components/api-reference-console.tsx
function curlSample(endpoint: ApiReferenceEndpoint): string {
  // …
  lines.push('  --header "Authorization: Bearer $PERISCAN_API_KEY"');
  // … Content-Type + --data from requestExample
}
```

OpenAPI marks proof-loop POSTs with optional `Idempotency-Key`, and runtime wires it (`withIdempotencyKey` on create/start mission, remediations, scopes). **Curl samples never emit that header**, so copy-paste automations won’t be retry-safe by default.
