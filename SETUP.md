# Setup

Canonical local / self-host guide: [`docs/SETUP.md`](docs/SETUP.md).

Need **Node 24** and **Docker**. Clone this repo, inspect it, then
`bash scripts/periscan.sh install` and `bash scripts/periscan.sh start`.

Default start is **Gitleaks-class secrets** (`jobsQueued=1`) on an authorized
**local clone path**. **Fixed** only after a retest. Keep proving.
